验证与兼容范围

Windows 通用技能包 1.0.0 Preview · 2026-10-05

已经验证

  • 14 项本地行为测试：API GET/分页/跨域拒绝/循环检测、工具过滤、100 KB 浏览器响应、路径穿越拒绝、CLI 路径安全、HTML 内容转义、答案隔离和链接处理。
  • 在独立 Windows 目录实际安装 Python 文档依赖及固定版本 Playwright MCP；复用已有 Node 与 Edge，未改动任何 AI 宿主配置。
  • 真实 MCP 初始化、工具列表过滤、拒绝 evaluate、隔离 headless Edge 打开 about:blank、snapshot 和关闭。
  • 合成 PDF 全文提取与原图渲染；离线 HTML 搜索、图片放大、Esc 关闭和 375/768/1440 像素布局。
  • Codex、Claude Code 的 MCP 注册命令通过本机 CLI help 核对。
  • 独立只读审阅，修复大响应、Python 检测、解释器选择和链接问题；发布前重新检查。

尚未声称验证

  • 未使用同学账号测试 API、OAuth 或三种宿主的真实课程端到端流程。
  • 本机没有 OpenClaw；其适配依据官方 Windows/Skills/Browser 说明，需要首次现场验证。
  • 缺少 Python/Node/Edge 时的下载分支有实现，但未在一台完全空白 Windows 机器上逐项实测；ARM64 未实测。
  • 学校网络限制、MFA、关闭 Token、外部 LTI 和宿主版本差异可能需要用户参与。

本包不是全平台“零配置认证”。首次环境检查、必要安装授权、登录/MFA 和宿主重载仍由使用者完成。

文件与隐私

包内只有技能规则、安装/读取/渲染脚本、固定依赖清单、指南和合成示例。没有课程文件、成绩、账号、Token、cookie、浏览器 profile 或个人配置。包内 SHA256SUMS.txt 验证解压内容完整性，不是数字签名。
