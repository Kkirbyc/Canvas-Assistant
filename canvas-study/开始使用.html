CANVAS ASSISTANT · WINDOWS · 1.0.0 PREVIEW

一份技能包，
从课程资料到图文复习。

面向 Windows 上能运行本地工具的 Codex、Claude Code、OpenClaw。优先复用已有 Canvas API；没有 API 时走浏览器。账号登录和 MFA 由你本人完成。

兼容性说明：通用脚本已在 Windows 验证；Codex 与 Claude 的 CLI 配置语法已核对。OpenClaw 提供官方能力对应的适配流程，但尚未在本机做端到端验证。Windows Hub / WSL / 远程 Gateway 需要按实际运行位置安装，不能保证仅复制本地文件就生效。

最简单的安装方式

  1. 完整解压，不要只复制 SKILL.md。保留 scripts、references、assets 等文件夹。
  2. 把解压目录交给你的 AI 工具，发送下方指令；或者使用后面的 PowerShell 命令。
  3. 首次批准必要安装，重载工具，再本人登录学校 Canvas。
  4. 告诉代理课程、考试日期和可用时间；预览后选择是否纳入 Lab/PA。

手动安装

在本文件所在目录打开 PowerShell。先预览，把 HostName 换成你的工具：

.\setup.ps1 -HostName codex
.\setup.ps1 -HostName codex -Apply

# Claude Code
.\setup.ps1 -HostName claude -Apply

# 原生 Windows OpenClaw：安装技能/文档工具，浏览器使用宿主能力
.\setup.ps1 -HostName openclaw -Apply

Python 已存在时也可用 python scripts/setup.py --host claude --apply。执行策略阻止时遵循安装指引，不要关闭整机安全策略。

第一次复习怎么说？

连接我的 Canvas，帮我准备 [课程名] 在 [日期] 的考试。
先预览课程，以 PPT、讲义和公告为主。
是否加入 Lab、PA 等内容，请预览后问我一次。
我要带老师原图、可以离线阅读的 HTML 复习资料。

默认数据目录：%USERPROFILE%\CanvasStudy。首次配置可能需要联网安装依赖；学习资料之后可以离线阅读。Token、密码和 MFA 不要发给代理或同学。
