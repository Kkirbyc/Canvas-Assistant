## 下载后怎么用

1. 下载 `canvas-assistant-windows-1.0.0-preview.1.zip` 并完整解压。
2. 打开 `canvas-study/开始使用.html`。
3. 按 Codex、Claude Code 或 OpenClaw 的实际运行位置完成配置。
4. 本人登录学校 Canvas/MFA，再让代理准备指定课程的考试。

附 `.sha256` 校验文件；这用于检查下载完整性，不是第三方签名。初始版本支持 Windows，未宣称所有宿主与学校零配置兼容。OpenClaw 尚未实机端到端验证；完整验证范围见仓库文档。
